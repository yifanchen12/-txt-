# 拾页图标、界面和推荐核验

本轮按用户已要求的范围执行：修复默认 Electron 图标，明显改善首页/书架界面，统一真实等待时的趣味加载动画；首页推荐先检验下载入口与正文。

## 复用与边界
- 沿用 Vite、原生 JS、Electron、Capacitor；沿用现有男女频分类、真实分页、封面回退、书源、书库和三种阅读方式。
- catalog.js 已有目录解析、章节正文、TXT 下载校验；把正文校验复用到推荐核验，不另写抓取规则。
- 新增 loading.js 统一等待组件，styles 统一动效。参考 Kazumi 官方 LoadingIndicator 的旋转变形方式，自绘形状。
- 新增品牌图标生成脚本；打包器嵌入 ICO，窗口和快捷方式使用同一图标，原生应用使用同一 PNG。
- 不改用户源配置、代理规则、已有正文和进度。

## 实现与验收
1. 图标：由 SVG 生成 PNG/ICO，产物可以重现；Windows 图标资源和窗口图标都设置。
2. 推荐：分类页只是候选；章节源读取完整目录并实测首、中、末章，文件源实际获取并校验 TXT。失败不展示；只读目录不算通过。分批核验、通过即追加，换分类取消旧任务。下载时重新解析入口，完整成功后才入库。UI 明确抽样范围，不声称已下载全书。
3. 界面：电脑侧栏、清晰的内容层级、深绿阅读主视觉、可读卡片；手机保持底部导航、合理字号与点击区域。保留蓝灰书名封面。
4. 加载：启动、搜索、榜单查源、后续推荐、下载和打开阅读器共用旋转变形组件，有实际进度时显示真实计数；不制造等待，不显示假百分比，照顾减少动态效果设置。
5. 检查：失败/取消/旧任务竞态测试，真实来源核验；桌面与手机视窗检查，运行新程序看图标和页面；生成 Windows/APK/unsigned IPA 发布并检查发布结果。

## 范围说明
抽样通过能证明该时刻下载链路和正文可用，不能保证远端每一章日后仍可取回。对用户展示「已实测正文」，完整下载仍逐章核验并在失败时拒绝把残缺正文存为完整书。
